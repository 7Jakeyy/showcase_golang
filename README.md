# Showcase Fullstack Developer: Golang & React

Repositori ini dibuat untuk memenuhi tugas penyelesaian kelas Fullstack Developer dengan Golang dan React di SantriKoding.com.

## 📂 Struktur Repositori
- `/backend` : RESTful API menggunakan **Golang** (Struktur: controllers, models, routes, database, dll).
- `/frontend` : Antarmuka web menggunakan **React.js & Vite**.

## 🛠 Teknologi yang Digunakan
- **Backend:** Go (Golang), GORM / Database Driver, Gorilla Mux / Gin (sesuai project)
- **Frontend:** React.js, Vite, TypeScript
- **Platform:** SantriKoding.com

## 📝 Keterangan
Project ini mengimplementasikan sistem Fullstack dari pembuatan API backend hingga integrasi frontend.
